This package contains the Capacitor Android app. It packages the shared web frontend from `../Frontend`.

- Use the existing web routes, daisyUI 5 components, and Lucide icons.
- Run npm commands from this directory. `npm run sync:local` builds and copies the web frontend and synchronizes Android.
- Run `npm run typecheck` after changing the Capacitor configuration.
- Generate native projects with Capacitor CLI. Keep local HTTP access confined to development builds.
